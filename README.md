# 🤖 chatbot-turnos

Este proyecto corresponde al trabajo final de la materia **Desarrollo de Software Cloud**. Consiste en un chatbot desarrollado en Python que permite gestionar turnos de forma automatizada, y se despliega utilizando contenedores Docker.

## 📦 Tecnologías utilizadas

- **Python 3**
- **Flask**
- **Docker**
- **Docker Compose**


## 🚀 Cómo ejecutar el proyecto

1. Clona el repositorio:
   bash
   git clone https://github.com/tu_usuario/chatbot-turnos.git
   cd chatbot-turnos
2. Crear .env con las mismas variables que .env-example con las claves necesarias.
3. Crear y levantar los contenedores.
   docker-compose up --build
4. Acceder a http://localhost:5000
